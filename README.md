# Personal Budget & Expense Tracker

A simple website for tracking income and expenses in one place.

## Features (Week 1)

- Page heading and description
- "Add Expense" form (name, amount in KES, category)
- "Your Expenses" placeholder section
- Emerald theme styled with CSS selectors

## Files

- `index.html`: page structure
- `style.css`: styling

## Run it

Download the files and open `index.html` in your browser.
